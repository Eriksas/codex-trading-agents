# V3 历史结论重审（2026-07-03）

## 结论

**「V3 五年半亏 9.89%」的历史定论被推翻：这个数字一半以上是指数数据失真造成的假象。**
用 BaoStock 重建指数后重跑同一条回测管线（唯一变量是指数数据），V3 真实表现为
**累计 -1.19%（年化 -0.24%），最大回撤 -3.85%，平均仓位暴露仅 2.0%**。

| 指标 | 旧结果（失真指数） | 修正后 | 变化 |
|---|---:|---:|---|
| V3 累计收益 | -9.89% | **-1.19%** | +8.7pp |
| V3 年化 | -2.05% | -0.24% | — |
| V3 最大回撤 | -11.12% | -3.85% | 大幅收窄 |
| V3 平均单笔 | -1.50% | -0.50% | — |
| v2 变体累计 | -13.76% | -2.99% | +10.8pp |
| v1 变体累计 | -37.84% | -16.99% | +20.9pp |
| legacy_momentum_v1 | -22.50% | -18.64% | 变化小（环境依赖低） |

年度分布（修正后）：2021 -2.6%，2022 +0.5%，2023 +0.3%，2024 +1.1%，2025 -2.3%，2026H1 +2.0%。

## 成因

`data/expanded/index/`（fuyao 源）自 2021 年中起漂移失真：2022-10 偏高 43.7%、
2023-12 偏高 44.0%、2026-06 偏低 25.3%（对照 BaoStock 与公开真实值多点核对）。
V3 的市场环境 gate（只在"积极"环境开仓）和 environment_exit 全部依赖该序列——
真实深熊被标成高位（放行开仓接刀），真实牛市被标成低位（禁止开仓错过修复）。
环境依赖越强的策略被污染越重（v1/v2/v3 修正幅度 >> legacy）。

失真原件已隔离备份至 `data/expanded/index_fuyao_corrupted_backup/`；
AGENTS.md 已加红线禁用 fuyao 指数源。**线上生产缓存（`data/cache/market_scanner/index`）
与 BaoStock 逐日核对 175 天零差异——每日推送的环境判断一直是干净的。**

## 如何解读修正后的 V3

1. **V3 不是亏钱机器，而是「2% 暴露的现金代理」**：五年半小额出手 356 笔，
   胜率 37.9%，靠风险预算仓位把单年波动压在 ±2.6% 以内。
2. **「近中性」的统计边界（反方审查后补）**：日度净值 20 日块自助 10,000 次，
   5.5 年累计收益 95% CI = **[-8.7%, +6.6%]**，P(累计≥0) = 32.6%。
   即「与零无法区分」是无法拒绝的零假设，**不是** V3 有效或中性的证据。
3. **回测口径合成数字说明（非策略表现，不构成任何收益预测）**：本回测 98% 闲置
   资金按 0 记账、alpha ≈ 0。若读者自行假设现金部分参照近年货基区间（1.5-2%/年），
   合成数字约 +1.3~1.8%/年——**该数字全部来自现金票息假设，与 V3 策略能力无关，
   不构成对未来的预测或承诺。**
4. **仍不能宣称 V3 为正**：本重审仍基于不复权价格、无退市股、静态 ST 快照。
5. **不自动恢复对 V3 的信心**：继续 forward paper 积累，不调参。

## 牛市切片审计（反方审查动作 3）

2025-07 ~ 2026-06（创业板 +89.2%）逐月对照：V3 单月收益始终在 ±1.7% 内，
段内累计 **+0.32% vs 创业板 +89.18%**；创业板最强月（2025-08 +24.4%）V3 为 -0.22%。

**直接解读：V3 的市场环境 gate 在牛市几乎从未放行。** 这不是数据缺陷，
是设计缺陷——「只在积极环境开仓 + 风险预算仓位」的组合把暴露压到 2%，
既躲过熊市也错过牛市，长期期望被成本和摩擦拖到微负。

## 八族重跑（修正指数，同框架对照）

strategy_discovery 八族用修正指数重跑后**仍全部为负，但从 -5%~-15% 收敛到
-1%~-8%**，且全部聚集在 V3 对照（-1.2%）附近。结合牛市切片，对旧研究纲领的
修正结论是：**过去两个月测试的从来不是「选股 alpha 是否存在」，而是同一个
2% 暴露执行框架的噪声**——任何选股信号在这个框架里都被 gate 和仓位压缩到
统计上不可分辨。未来研究应先修框架（gate 的牛市失效、暴露量级），再谈信号。

## 「唯一变量」声明的 A/B 复现（已完成，声明成立）

反方审查要求的严格 A/B 已执行：同一 commit（5f6e2bd）、同日、仅指数目录不同。

| 策略 | BaoStock 指数 | fuyao 失真指数 | 指数效应 |
|---|---:|---:|---:|
| v1（gate 依赖最深） | -16.99% | -42.64% | **+25.65pp** |
| v2 | -2.99% | -15.33% | **+12.34pp** |
| v3 | -1.19% | -9.97% | **+8.78pp** |
| legacy（弱环境依赖） | -18.64% | -23.25% | +4.60pp |
| baseline_current_stop（**无环境 gate**） | -113.06% | -112.70% | **-0.36pp（噪声）** |

三重证据闭合：
1. 坏指数 A/B 跑出 -9.97%，与数周前旧存档 -9.89% 仅差 0.08pp → 代码等价性确认；
2. 指数效应与 gate 依赖度单调对应（v1 > v2 > v3 > legacy）；
3. **无 gate 的内部对照组指数效应为零**——这回答了审查提出的「为何没有反向修正」：
   不吃环境信号的策略确实不动。
「修正幅度主要由指数失真解释」由此从假设升级为已证实的因果结论。
