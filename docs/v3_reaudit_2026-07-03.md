# V3 历史结论重审（2026-07-03）

## 结论

**「V3 五年半亏 9.89%」的历史定论被推翻：这个数字一半以上是指数数据失真造成的假象。**
用 BaoStock 重建指数后重跑同一条回测管线（唯一变量是指数数据），V3 真实表现为
**累计 -1.19%（年化 -0.24%），最大回撤 -3.85%，平均仓位暴露仅 2.0%**。

| 指标 | 旧结果（失真指数） | 修正后 | 变化 |
|---|---:|---:|---|
| V3 累计收益 | -9.89% | **-1.19%** | +8.7pp |
| V3 年化 | -2.05% | -0.24% | — |
| V3 最大回撤 | -11.12% | -3.85% | 大幅收窄 |
| V3 平均单笔 | -1.50% | -0.50% | — |
| v2 变体累计 | -13.76% | -2.99% | +10.8pp |
| v1 变体累计 | -37.84% | -16.99% | +20.9pp |
| legacy_momentum_v1 | -22.50% | -18.64% | 变化小（环境依赖低） |

年度分布（修正后）：2021 -2.6%，2022 +0.5%，2023 +0.3%，2024 +1.1%，2025 -2.3%，2026H1 +2.0%。

## 成因

`data/expanded/index/`（fuyao 源）自 2021 年中起漂移失真：2022-10 偏高 43.7%、
2023-12 偏高 44.0%、2026-06 偏低 25.3%（对照 BaoStock 与公开真实值多点核对）。
V3 的市场环境 gate（只在"积极"环境开仓）和 environment_exit 全部依赖该序列——
真实深熊被标成高位（放行开仓接刀），真实牛市被标成低位（禁止开仓错过修复）。
环境依赖越强的策略被污染越重（v1/v2/v3 修正幅度 >> legacy）。

失真原件已隔离备份至 `data/expanded/index_fuyao_corrupted_backup/`；
AGENTS.md 已加红线禁用 fuyao 指数源。**线上生产缓存（`data/cache/market_scanner/index`）
与 BaoStock 逐日核对 175 天零差异——每日推送的环境判断一直是干净的。**

## 如何解读修正后的 V3

1. **V3 不是亏钱机器，而是「2% 暴露的近似打平」**：五年半在深熊+疯牛交替中
   小额出手 356 笔，胜率 37.9%，靠风险预算仓位把单年波动压在 ±2.6% 以内。
2. **现实语境**：回测中闲置资金记零收益。以 2% 平均暴露计，若 98% 资金放货基
   （近年约 1.5-2%/年），全账户现实预期约 +1.3~1.8%/年——这已经接近"非负收益"
   的诚实形态，但收益来源主要是现金，不是策略 alpha。
3. **仍不能宣称 V3 为正**：本重审仍基于不复权价格（除权假暴跌会触发假止损，
   方向偏负；BaoStock 复权因子到位后需再复核一轮）、无退市股、ST 过滤为静态快照。
4. **不自动恢复对 V3 的信心**：356 笔、37.9% 胜率、-0.24%/年仍是"未证明有效"，
   只是从"证明失败"回到"接近中性"。继续 forward paper 积累，不调参。
