# 项目重构说明（2026-07-03）

## 1. 背景与动机

重构前项目约 32,600 行 Python 代码，主要问题：

1. **研究代码链式继承**：`factor_research_round6 → round5 → round4 → round3 → factor_research`，每一轮研究直接 import 上一轮的内部函数，没有共享库。
2. **运行路径被研究链绑架**：每日飞书推送用的 `scheduled_v3_reporter` 和 `forward_paper_trading_v3` 需要 import 三个研究轮次文件才能跑。
3. **一次性脚本堆积**：6 轮因子研究（约 8,000 行）、7 个诊断/shadow 脚本、3 个 main 入口混在 `src/` 和 `scripts/` 里，无法分辨哪些代码是"每天在用的"。

## 2. 负收益问题的定性（重要）

重构前抽查了回测核心 `_simulate_alpha040_trade` 的方法论：

- 进场：信号次日起在触发区间内成交，涨停日禁止买入；
- 出场：止损优先于止盈（同日双触发按止损计）、跌停/停牌日禁止卖出顺延；
- 成本：双边费用（5bp/边）+ 双边滑点（10bp/边）。

结论：**回测偏保守而非偏乐观，长样本负收益是真实研究结论，不是代码缺陷**。唯一已知的乐观偏差是"跳空跌破止损仍按止损价成交"（真实成交会更差），即真实结果只会比回测更糟。因此本次重构不试图通过改代码"修复收益"——那属于策略研究问题，且项目规则明确禁止小样本调参。

另注意：对比表中 `baseline_current_stop` 的"累计收益 -111%"是**逐笔收益加总口径**（net_return × 仓位的算术和），不是复利净值口径，故可能超过 -100%。诊断用途可以，但对外表述时应说明口径。

## 3. 重构内容

### 3.1 三层目录

| 层 | 目录 | 规则 |
|---|---|---|
| 每日运行 | `src/` + `main_v2.py` | 定时任务和 shell 脚本只允许调用这一层 |
| 研究 | `research/` | 可以 import `src/`；`src/` 不得反向 import |
| 归档 | `archive/` | 弃用入口与 legacy 策略，仅回滚/对照用 |

### 3.2 新共享库 `src/quant_core.py`

把运行路径真正依赖的函数从研究链中原样抽出（约 25 个函数，行为经等价测试验证）：

- 数据缓存：`load_cached_histories`、`_load_bars_csv`、`_symbol_from_cache_path`
- 市场环境：`_market_timeline`、`_market_timeline_from_cache`
- 可交易性：`_is_limit_up/_is_limit_down/_is_suspended_or_untradeable/_can_sell/_prev_close_from_bars`
- 股票池：`_build_dynamic_universe`、`_build_alpha040_map`、`_standardize`、`_date_index`
- V3 策略：`ShadowStrategy`、`_alpha040_core_score`、`_passes_strategy_filters`、`_eligible_for_strategy`

`forward_paper_trading_v3.py` 与 `scheduled_v3_reporter.py` 全部改为 `import quant_core as qc`，不再依赖 `research/` 下任何文件。

### 3.3 文件迁移对照

| 原路径 | 新路径 |
|---|---|
| `src/factor_research*.py`（7 个） | `research/` |
| `src/backtest_v3_expanded.py`、`src/data_expansion_pipeline.py`、`src/main_strategy_upgrade_v3.py` | `research/` |
| `src/setup_based_short_swing.py`、`src/automated_setup_review.py` | `research/` |

研究轮次文件内容未改动（历史结果可复现）；仅 `main_strategy_upgrade_v3.py` 的 `sys.path` 增加了 `archive/`（其 legacy 对照基准所在）。

### 3.4 保持不变

- `market_scanner.py`、台账、策略配置、冻结规则、回测口径全部未动。
- GitHub Actions 引用的入口（`main_v2.py`、`src/market_scanner.py`、`src/scheduled_v3_reporter.py`、`src/forward_paper_trading_v3.py`）路径未变。
- `strategy.json`、`freeze_v3_strategy.json`、`strategy_legacy_v1.json` 未动。

- 运行核心 import 与 `--help` 冒烟通过：`quant_core`、`forward_paper_trading_v3`、`scheduled_v3_reporter`、`market_scanner`、`main_v2`。

## 5. 后续维护规则

1. 新的共享函数进 `src/quant_core.py`，禁止再从研究轮次文件 import。
2. 新实验一律放 `research/`，用独立文件，不改运行核心。
3. 研究收敛后（结论为负或放弃），文件留在 `research/` 并在 `research/README.md` 标注状态，不要回流 `src/`。
4. 距离下次策略讨论的前置条件不变：forward paper trading 累计 30-50 笔 closed trades。
