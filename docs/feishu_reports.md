# 飞书日报

日报检查规则是否触发、记录如何变化、数据是否完整。正文依次给出**结论、依据、解释、局限和下一步**，参数明细放后面；单日报告不能证明策略长期有效。

## 阅读口径

- 目标比例是规则输出，不是实际持仓；25% 到 50% 是增加 25 个百分点。
- 同日多只股票不扩大独立事件数；模拟持有与等待入场分别计数。
- 过滤原因按首个失败条件计数，不等于各因素的收益贡献。
- 数据日期以各项记录为准；旧记录、缺失和重复会明确提示，季度名单无需每天更新。
- 转债低价数量和涨停数量是辅助观察；缺分母不算占比，没有对照不作因果判断。

## 生成与推送

两条现有云端 Python 路径继续使用 Actions Secrets，无需新增模型配置：

| 报告 | 生成入口 | 输出 |
|---|---|---|
| V3 日报 | [scheduled_v3_reporter.py](../src/scheduled_v3_reporter.py) | `output/日期/v3_daily_report.md` |
| 前向观察 | [forward_daily_report.py](../research/forward_daily_report.py) | `/tmp/forward_daily_report.md` |

[notifier](../src/notifier.py) 支持 full/digest，摘要保留依据与局限。前向报告可通过 `--state-dir`、`--date`、`--output` 生成只读预览；发送配置见[推送说明](push.md)。合成预览与段落转换测试不代表真实消息已送达。

## 面试时的解释

“我先限定日报的问题，再用台账数据给出依据。目标比例变化只能说明规则输出变化，不能直接推断收益改善。样本不足或缺少对照时，我保留未知，并写明下一项验证。”
