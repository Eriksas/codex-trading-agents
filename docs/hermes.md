# Hermes Strategy Steward

Hermes Agent is used as a read-only strategy steward. It consumes the deterministic
health and review files generated by this project, then writes diagnosis reports
or experiment drafts. It must not modify `strategy.json`, ledgers, or scan outputs.
It should treat shadow experiment files as evidence, not as automatic promotion
instructions.

## Run

Generate the prompt only:

```bash
scripts/run_strategy_steward.sh --date 2026-06-26 --dry-run
```

Run Hermes and write the daily diagnosis:

```bash
scripts/run_strategy_steward.sh --date 2026-06-26 --mode daily
```

Outputs:

```text
output/YYYY-MM-DD/scan/strategy_steward_prompt.md
output/YYYY-MM-DD/scan/strategy_steward_report.md
```

## Modes

```bash
# Regular diagnosis
scripts/run_strategy_steward.sh --date 2026-06-26 --mode daily

# Longer drift diagnosis with more historical context
scripts/run_strategy_steward.sh --date 2026-06-26 --mode deep

# Red-team the previous Hermes report
scripts/run_strategy_steward.sh --date 2026-06-26 --mode critic

# Draft JSON experiments without touching the main strategy
scripts/run_strategy_steward.sh --date 2026-06-26 --mode experiment
```

Mode outputs:

```text
output/YYYY-MM-DD/scan/strategy_steward_report.md
output/YYYY-MM-DD/scan/strategy_steward_deep_report.md
output/YYYY-MM-DD/scan/strategy_steward_critic.md
strategy_experiments/YYYY-MM-DD/hermes_experiments.json
```

`experiment` mode validates Hermes output as JSON. If Hermes returns Markdown or
invalid JSON, the script writes a safe fallback JSON object with `experiments: []`
and `raw_output` for manual review.

## Scan Integration

Run a scan and append a short Hermes digest to `scan_report.md`:

```bash
python3 src/market_scanner.py --date 2026-06-26 --steward --steward-mode daily
```

The Feishu digest includes only the Hermes mode/status, report path, and up to
three core diagnosis lines. It does not push the full long-form Hermes report.

When Hermes is enabled from the scanner, the deterministic learning memory is
also updated:

```text
data/strategy_learning/learning_memory.json
data/strategy_learning/learning_memory.md
output/YYYY-MM-DD/scan/strategy_learning_summary.json
output/YYYY-MM-DD/scan/shadow_experiments_summary.json
output/YYYY-MM-DD/scan/shadow_experiments_report.md
```

Hermes reads `prompts/hermes_market_learning_skill.md` and the current learning
memory on the next run. Hermes still does not write memory directly.

Manual memory refresh:

```bash
python3 src/strategy_learning.py --date 2026-06-26 --output output
```

## Provider

The local Hermes install is expected to use the configured default model/provider.
Optional overrides:

```bash
HERMES_PROVIDER=minimax-cn HERMES_MODEL=MiniMax-M3 scripts/run_strategy_steward.sh --date 2026-06-26
```

## Safety Boundary

- `strategy_health.py` computes facts.
- Hermes explains facts and proposes experiment hypotheses.
- `strategy_learning.py` updates long-term lessons from deterministic evidence.
- Hermes must not update main strategy parameters.
- Any parameter experiment is saved separately under `strategy_experiments/`
  and must be validated by backtest before promotion.
