# 项目整体报告（2026-07-08）

替代 `docs/project_overall_report_2026-06-29.md`。本报告由四份阶段文档（V3 重审、2026-07 策略搜索、框架修复轮、2026-07-03 重构说明）合并起草。所有数字均来自原文档，未新增。

## 一、项目定位

本项目是个人量化辅助与 AI 工具落地探索项目，用于验证 Codex Sub-agents 在金融数据协作工作流、收盘扫描、模拟交易计划生成中的适用边界。它是个人使用的工程模式探索（数据抓取、候选筛选、风控参数生成、任务分工、上下文传递、产出聚合），不是自动化实盘交易系统、不是投资顾问工具、不是生产级金融产品。所有产出定位为个人模拟交易计划，与 `AGENTS.md` 与 `HERMES.md` 一致。

## 二、安全边界（硬红线）

引自 `AGENTS.md` 与本轮研究结果：

- 不连接实盘交易接口，不承诺收益、胜率或风险可控。
- 不编造数据；抓取失败或计算异常必须明确报错、明确标注。
- 不使用 fuyao 源指数数据：已证实自 2021 年中起至 2026 双向漂移（沪深300 2023-12-29 记录 4940 vs 真实 3431，偏差 +44%）。指数数据一律以 BaoStock 序列为准（`data/expanded/index_daily_baostock.csv`）；失真原件隔离备份于 `data/expanded/index_fuyao_corrupted_backup/`。
- ST/*ST 股票全链路剔除（扫描、候选、回测、forward paper）。回测需使用时变 ST 状态（BaoStock isST 日频序列），静态 ST 快照仅为过渡。
- 不在小样本上调参；forward paper trading 累计 30-50 笔 closed trades 之前不视为有效策略。
- 重构分层约束（2026-07-03）：`src/` 是唯一每日运行层；`research/` 可 import `src/`，反向禁止；新共享函数入 `src/quant_core.py`，不得再从研究轮次文件 import。

3. 股票价格数据本身可靠：茅台、平安银行等多点核对与真实值一致。

4. 环境判断逻辑（`src/quant_core.py` 内 `_market_timeline`）：每日推送源已不依赖失真指数。

### 3.3 残余偏差（精确量化）

1. 退市股缺失：约 330 只长周期退市股无历史。终审反推 188 只退市股中仅 18 只在退市前 120 日仍满足 universe 过滤，**EW500 配置幸存者偏差实测约 -0.28%/年**（远小于事前担心的 1-2%/年）。残余偏差方向为收益上偏。

3. 启发式除权检测残差：覆盖率 8.2%、误检 4.0%；已建真复权终审替代方案。
4. 静态 ST 快照：composite3_h15 训练段由静态 ST 下 +7.1% 翻至时变 ST 下 -3.1%，证明部分样本内优势来自 ST 口径差。

## 四、主策略 V3 现状（重审后）

### 4.1 历史定论被推翻

旧结论「V3 五年半亏 9.89%」一半以上是指数数据失真的假象。同 commit（5f6e2bd）、仅替换指数目录后的 A/B：

| 指标 | 旧结果（失真指数） | 修正后 | 变化 |
|---|---:|---:|---|
| V3 累计收益 | -9.89% | **-1.19%** | +8.78pp |
| V3 年化 | -2.05% | -0.24% | — |
| V3 最大回撤 | -11.12% | **-3.85%** | 大幅收窄 |
| V3 平均单笔 | -1.50% | -0.50% | — |
| v2 累计 | -13.76% | -2.99% | +10.77pp |
| v1 累计 | -37.84% | -16.99% | +20.85pp |
| legacy_momentum_v1 | -22.50% | -18.64% | +3.86pp |
| baseline_current_stop（无 gate） | -113.06% | -112.70% | -0.36pp（噪声） |

三重证据闭合：
- 坏指数 A/B -9.97% 与旧存档 -9.89% 差 0.08pp → 代码等价；
- 指数效应大小与 gate 依赖度单调对应（v1 > v2 > v3 > legacy）；
- 无 gate 的内部对照指数效应为零 → 反向修正不自相矛盾。

### 4.2 修正后 V3 的形态与统计边界

- V3 在修正数据上是 **2% 暴露、现金代理**：5.5 年 356 笔、胜率 37.9%；
- 年度分布（修正后）：2021 -2.6%，2022 +0.5%，2023 +0.3%，2024 +1.1%，2025 -2.3%，2026H1 +2.0%；
- 日度净值 20 日块自助 10,000 次：5.5 年累计收益 95% CI = **[-8.7%, +6.6%]**，**P(累计 ≥ 0) = 32.6%**。

解读：与零无法区分的零假设目前无法拒绝；**既不是 V3 有效的证据，也不是 V3 中性的证据**。回测口径下 98% 闲置资金按 0 记账；如读者自行假设现金部分参照近年货基区间（1.5-2%/年），合成数字约 +1.3~1.8%/年——该数字全部来自现金票息假设，与 V3 策略能力无关，不构成对未来预测。

### 4.3 牛市切片审计

2025-07~2026-06 创业板 +89.18% 段：
- V3 段内累计 +0.32%，单月收益始终在 ±1.7% 内；
- 创业板最强月 2025-08 +24.4%，V3 当月 -0.22%；

**直接读出**：V3 的市场环境 gate 在牛市几乎从未放行。这是设计缺陷——「只在积极环境开仓 + 风险预算仓位」组合把暴露压到 2%，既躲过熊市也错过牛市，长期期望被成本和摩擦拖到微负。

### 4.4 连带影响

- 既往所有依赖失真指数的研究结论（strategy_discovery 八族、setup 实验、短线 shadow 系列）的绝对数值不可引用。
- 八族重跑（修正指数、同框架）：**仍全部为负**，但从 -5%~-15% 收敛到 **-1%~-8%**，全部聚集在 V3 对照（-1.2%）附近。

### 4.5 不做的事

## 五、研究结论地图（搜索轮 + 框架轮，全部负结果如实呈现）

### 5.1 2026-07 策略搜索轮（61 配置、三段样本外）

- 协议：训练 2021-01~2023-12（沪深300 -34.9% 深熊）；验证 2024-01~2025-06；holdout 2025-07~2026-06（暴力牛市，创业板指 +95.3%）；执行 T+1 开盘、双边成本 30bp；全部 61 配置留痕 `trial_registry.jsonl`；holdout 一次性解锁。
- 直接结论：**没有找到高仓位、全天候、三段均非负的选股策略**。

| 候选 | 训练 | 验证 | holdout | 终审判定 |
|---|---:|---:|---:|---|
| abturn_h20（异常缩量） | +14.7% | +30.4% | **-2.9%** | 淘汰：风格代理 + holdout 负 |
| composite3_h15（反转+冷门+反彩票） | **-3.1%** | +29.3% | -0.2% | 淘汰：时变 ST 下训练转负 |
| idx1000_bounce_h5（恐慌反弹） | +1.3% | +1.6% | +0.8% | 三段全正但更薄（5.5y 合计 +3.7%）；样本不足，仅记录 |
| bl_ew500_h20（等权 500 月度轮动） | +13.4% | +7.6% | +7.7% | 基线观察；偏差实测 -0.28%/年（有界） |
| 随机 10 只 ×5 | -2.4%~-11.7% / +6.0%~+24.3% / +12.8%~+21.2% | — | 运气带 |
| rev20 短期反转 ×3 | -23%~-33% | — | — | 淘汰：长 only 日频接飞刀负期望 |
| limitdown_recover_h2 | -96%（训练 931 笔） | — | — | 淘汰：灾难 |

idx1000_bounce_h5 在反方审查后的置换检验：同触发日随机选 10 只期望 +0.86% vs 策略实选 +0.67%，p=0.61；触发日相对随机日期的正向择时迹象 p=0.21（12 次事件）。**ADV-top10 选股规则无任何附加值**；「三段全正」的正确解读是 61 配置筛选后的幸存者，统计功效为零。

abturn_h20 在风格匹配置换检验：实选 +0.89%/笔 vs 同风格随机 +0.83%/笔（t=0.19）；无条件随机 +0.50%。**缩量信号本身的增量贡献为零**，全部超额来自低流动性 × 低波动的风格箱。「体制条件性 alpha」措辞撤回，abturn 存档为负结果。

### 5.2 2026-07-04 框架修复轮（36 配置，4 框架 × 2 篮子 × 3 段）

候选：G2 趋势投票集成、G3 下行半方差×多尺度动量、G4 回撤阶梯、G5 双层取小。篮子：B1 流动性前 10、B2 随机 300 等权。对照：G0 满仓、G1 = V3 原版 gate 在修正指数上的复现、G6 = 固定 25% 暴露零模型。

按预声明标准（训练与验证两段 Calmar 均优于满仓对照且累计非负），4 个候选框架**无一通过**。

B2 宽基篮训练/验证段：

| 框架 | 训练 cum / Calmar | 验证 cum / Calmar | 判定 |
|---|---|---|---|
| G0 满仓 | -2.4% / -0.03 | +15.6% / 0.46 | 对照 |
| G1 V3 原版 | +0.5% / 0.06 | +1.2% / 0.27 | 两段非负但验证 Calmar 低于 G0，未过 |
| G2 趋势投票 | +2.2% / 0.09 | -2.0% / -0.11 | ✗ |

| G4 回撤阶梯 | -2.2% / -0.05 | +6.0% / 0.30 | ✗ |

已烧毁段 labeled 参考（不构成证据）：四框架暴露自动升至 62-95%，B1 +98%~+149%、B2 +8.6%~+13.3%；**G1 在此段录得 -1.7%~-2.3%（3% 暴露、69 次强制清仓）**——V3 原版 gate 在牛市依然完整体现设计缺陷。

G2 反事实校准（无摩擦、零成本）：验证段可达 +22.5%；改用日度 overlay（delta 计费单边 15bp）后 G2 验证 +20.4%（Calmar 1.35 胜 G0）。**但训练段 -2.3%**——结论方向不变，归因更准确：2021-2025H1 存在 G2 可捕获的脉冲结构，但本轮引擎分批滞后抹掉了部分信号。

faber_basket 事后观察：在验证集 -14% 淘汰，holdout 补测录得 +145.6%（top-ADV 篮子自动集中到 2025H2 AI 算力硬件主线）。**事后好看是幸存者叙事的教科书案例，不构成策略结论**；与 V3 gate 「牛市不放行」互为镜像，共同指向命题：「gate/暴露框架的设计比选股信号重要一个数量级」。

### 5.3 总览：把假设空间压到了哪里

- 「在 2% 暴露框架里挑选股信号」整片被证伪：八族重跑全负且收敛到 V3 对照附近。
- 「指数级择时 gate 在 2021-2025H1 提供超额」被证伪：G6 零模型 25% 暴露胜过所有聪明 gate，事后归因。
- 「短期反转 / 跌停开板 / 长 only 日频接飞刀」被证伪（与文献设定差异巨大）。
- 「中证 1000 恐慌反弹 + ADV-top10」在 12 次事件、t≈0.5 下不能证伪也不能证实；统计功效为零。
- 「缩量异象 = 体制条件性 alpha」被证伪为风格代理，措辞撤回。

## 六、前向观察体系（三条线、协议、自动化）

### 6.1 三条 forward 线

- 线 A：V3 forward paper trading（既有），不调参；累计 30-50 笔 closed trades 之前不视为结论。
- 线 B：`idx1000_bounce_h5` 进入 forward paper 观察（中证 1000 五日跌幅 ≤ -5% 且当日收阳且 60 日跌幅 > -25% 触发，次日开盘买入成交额 300-1500 名中盘股 10 只，持有 5 日，冷却 5 日）。**预期管理**：95% 时间持币；事件年均 2-3 次；即便有效年化贡献约 1-3%；组合含现金的现实预期年化 2-5% 量级（这是「非负」目标下诚实的收益量级，不构成承诺）。不满 20 次事件前不调参、不下结论。
- 线 C：`forward_gate_recorder.py` 每日收盘后从 BaoStock 指数计算 G2 趋势投票、G4 回撤阶梯两框架的目标暴露并留痕（paper only）。协议已冻结为 `forward_gate_recorder.PROTOCOL_V1`。

### 6.2 线 C 协议要点（已锁，不可作弊）

- 主决策点：Day250（约一年）。
- 对照含 G0（满仓）与 G6（固定 25% 暴露零模型），双框架 Bonferroni 校正。
- 决策前不得调阈值；Day250 后改阈值即作废。
- 这是数据收集，不构成 G2/G4 晋级。

### 6.3 自动化边界

- 每日 GitHub Actions 仅调用 `main_v2.py`、`src/market_scanner.py`、`src/scheduled_v3_reporter.py`、`src/forward_paper_trading_v3.py`；重构后无路径变化。

## 七、风险与边界（按提示保留为专项小节）

- 多重检验：搜索轮 61 配置、框架轮 36 配置；任意「三段全正」或「Calmar 优」都可能是幸存者。三段筛选同日顺序执行，holdout 未参与筛选决策（registry 时间戳可证），但它不是时间意义上的真 forward 样本——真正的时间上锁样本从 2026-07-03 forward paper 起算。
- 样本不足：idx1000_bounce_h5 在 5.5 年仅 12 次事件，t≈0.5；V3 累计 356 笔仍是 2% 暴露的小子集；任何结论需继续 forward 积累。
- 偏差互不抵消：退市股缺失向上偏 vs 分红漏损向下偏；均已披露、不可精确抵消。
- 持续红线：失真指数、实盘连接、ST 全链路剔除、小样本调参——四项硬约束本轮无松动。
- 非策略表现：本回测 98% 闲置按 0 记账；任何现金票息假设下的合成数字全部来自假设，与 V3 能力无关。
- 「修正幅度主要由指数失真解释」已升级为因果结论（A/B + 单调对应 + 零效应对照三证据闭合），但「修正后 V3 有效或中性」仍未证实。
