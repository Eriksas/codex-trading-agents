# 执行框架修复轮报告（2026-07-04）

> shadow research；不修改生产 V3；不构成收益承诺。

## 1. 结论先行

**按预声明标准（训练与验证两段 Calmar 均优于满仓对照且累计非负），
4 个候选框架无一通过。本轮不晋级任何框架。**

但结构目标达成且对照发现重要：
- 四框架把宽基篮回撤从 -26% 压到 -8%~-16%，暴露随趋势渐进（结构性能如设计）；
- 收益端失败的根因是样本本身：2021-2025H1 的 A 股指数层面没有可持续趋势
  （训练段阴跌熊、验证段仅政策脉冲后震荡）——全样本唯一的持续上升趋势
  位于已烧毁段内，无法用于选择；
- **V3 原版 gate（G1）的结构缺陷获得终版演示**：在已烧毁段（大牛市）的
  labeled 参考测量中，G1 仅 3% 暴露、69 次强制清仓、收益 -1.7%~-2.3%——
  即使在修正后的指数上，二元「积极才开仓」依然完整错过牛市且反复鞭打。

## 2. 协议（先声明后执行）

- 候选：设计面板 9 提案 → 代审筛出 4 个机制正交框架（趋势投票集成 G2、
  下行半方差×多尺度动量 G3、回撤阶梯 G4、双层取小 G5），参数全部
  文献/惯例默认值（海龟 20/10、55/20；Faber MA 阶梯；RiskMetrics λ=0.94；
  Harvey σ_target=15%；Ned Davis 10%/20% 回撤档；Carver 0.10 缓冲）。
- 对照：G0 恒定满仓、G1 = V3 原版环境 gate 在修正指数上的复现。
- 篮子：B1 流动性前10（集中 beta）、B2 随机300等权（分散 beta）。
- 选择只用训练+验证段；2025-07 后为已烧毁参考段（仅标注展示）。
- 执行近似：批次开仓锁定权重、约半持有期滞后跟踪目标；崩塌硬切即时。

## 4. 判读

1. 指数级趋势/波动框架在无趋势样本中的两段检验失败是**该时期的诚实测量**，
   不是实现缺陷（缓冲、滞后近似经手工算例与暴露曲线检查）。
2. 不在同一数据上继续迭代 gate 设计——从现在起那是数据挖掘。
3. G1 两段非负再次说明：极端保守在无趋势样本里"对"，其成本只在牛市可见；
   这正是为什么框架选择不能只看历史回测，必须积累真实前向样本。

## 5. 决定与下一步

1. **G2（趋势投票）与 G4（回撤阶梯）进入 forward gate 状态每日记录**
   （`research/forward_gate_recorder.py`，paper only）：每日收盘后从 BaoStock
   指数计算两框架目标暴露并留痕。这是唯一不可作弊的检验。
2. 生产 V3 不变；任何框架替换需 forward 证据 + 人工确认 + 可回滚。
3. 信号研究重启的前置条件改为：**在新框架的暴露量级下重测信号族**
   （历史上所有"信号无效"结论都是 2% 暴露下的测量，不可比）。
   重测可用本轮框架做暴露载体，但结论同样受"选择需前向样本"约束。
4. 多重检验披露：本轮 36 个配置（6 框架 × 2 篮子 × 3 段）全部留痕。
