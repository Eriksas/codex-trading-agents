## 接入与验证结果（2026-07-08，research/fuyao_client.py 冒烟 12/12 通过）

- **第二个失真面实锤：fuyao 复权价禁用。** adjust=backward 的日收益率相对
  BaoStock/交易所口径被恒定阻尼约 0.78 倍（平安银行六个交易日逐日对比）。
  prices 端点在客户端中已硬编码 adjust="none"。
- **原始不复权价干净**：与 BaoStock 逐日一致——生产扫描器（一直用 raw）不受影响。
- 参数破译：日线 `start/end` 毫秒戳 + `interval=1d`；财务指标 `report={yyyy}-{1|2|3|4}`；
  利润表 `period=annual`；热榜/龙虎榜等特色数据仅保留**近一年**（超期 code=1003），
  意味着注意力类信号的回测窗只有约 1 年且与烧毁段重叠——研究设计必须如实标注。
- 涨停池历史至少回溯 2024-01（超过一年，与热榜留存策略不同）。
- 茅台分红事件流 30 条（dividend_per_share/per_share_bonus）——分红漏损的精确
  修正数据源，可与 BaoStock hfq 因子跳变交叉验证。

## 使用红线（沿用 AGENTS.md）

- fuyao **指数历史**与**复权价**均已实锤失真，双双禁用；只用其原始价与非价格类数据。
- 新数据族启用前每一族先与独立源交叉验证，验证记录入 docs，未验证不得进入回测。
