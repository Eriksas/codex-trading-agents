## 使用红线（沿用 AGENTS.md）

- fuyao **指数历史数据**曾实锤失真（±44%），已被红线禁用；
  本次新数据族启用前**每一族都必须先与独立源交叉验证**（BaoStock/公开值抽查），
  验证记录入 docs，未验证不得进入回测。
- 1003 返回码待查：可能是参数名或 key 权限档位问题，读文档页参数表后重试。
