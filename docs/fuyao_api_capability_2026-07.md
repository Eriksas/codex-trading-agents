# Fuyao API 能力勘探（2026-07-08）

背景：项目此前只用了 fuyao（同花顺扶摇，fuyao.aicubes.cn）的 5 个价格端点。
本次勘探（sitemap + llms.txt + 实测）发现能力面远大于此。key 位于
`~/.secrets/fuyao_api_key`，认证头 `X-api-key`。

**⚠ 快照陷阱（2026-07-09 实锤，修正本文此前错误结论）**：特色数据端点的
`date` 参数被**完全无视**——任何日期（含 2016/2019/2023）返回同一份最新快照，
且 code=0 不报错（hot-history 仅对超一年日期做格式校验，同样不按日期查询）。
此前「2024-01 历史可查」的记录是错误的（只验了 code=0 未验内容差异）。
**结论：fuyao 特色数据只能做前向逐日积累，无历史可回测。**
涨停生态的历史已改由自有面板推导（`research/thermometer_study.py`，
2016-2026 十年全量，描述性结论：与前瞻指数收益仅微弱非线性关联——
极端连板→小盘 20 日 -1.31%（Q5）、跌停潮→反弹倾向，均不足以构成规则）。
| 个股异动原因 | anomaly-analysis | 未测 | 事件标注 |

## 接入与验证结果（2026-07-08，research/fuyao_client.py 冒烟 12/12 通过）

- **第二个失真面实锤：fuyao 复权价禁用。** adjust=backward 的日收益率相对
  BaoStock/交易所口径被恒定阻尼约 0.78 倍（平安银行六个交易日逐日对比）。
  prices 端点在客户端中已硬编码 adjust="none"。
- **原始不复权价干净**：与 BaoStock 逐日一致——生产扫描器（一直用 raw）不受影响。
- 参数破译：日线 `start/end` 毫秒戳 + `interval=1d`；财务指标 `report={yyyy}-{1|2|3|4}`；
  利润表 `period=annual`；热榜/龙虎榜等特色数据仅保留**近一年**（超期 code=1003），
  意味着注意力类信号的回测窗只有约 1 年且与烧毁段重叠——研究设计必须如实标注。
- 涨停池历史至少回溯 2024-01（超过一年，与热榜留存策略不同）。
- 茅台分红事件流 30 条（dividend_per_share/per_share_bonus）——分红漏损的精确
  修正数据源，可与 BaoStock hfq 因子跳变交叉验证。

## 全市场 Parquet 导出（2026-07-08 已接入并验证）

端点：`GET /api/dump/market-dumps/{daily-k|daily-k-10d|adjustment-factors}/download-url`
（返回预签名链接；客户端 `fuyao_client.dump_download_url()`）。
落地目录：`data/expanded/fuyao_dumps/`（gitignore，本地）。

| dump | 验证结果 |
|---|---|
| 10y 日K | 1,013 万行 / 5,523 只 / **2016-07-08 ~ 2026-07-08**；茅台已知值精确命中；**不含退市股**（幸存者补丁仍走 BaoStock 退市数据） |
| 10d 增量 | 5.5 万行，日常刷新窗口 |
| 复权因子事件流 | 56,541 事件 / 5,412 只；茅台 2026-06-26 分红反推因子 vs BaoStock hfq 跳变**偏差 0.00036%** ✓ |

**可信数据栈定型**：fuyao 原始价（已验证干净）+ fuyao/BaoStock 复权事件流（互证）
+ BaoStock 退市股（幸存者补丁）+ BaoStock 指数。数据历史从 2021 向前延伸到 2016
（多出 2016-2020 完整体制段），且可刷新至当日——面板迁移到此数据栈是下一轮任务，
迁移时需与现有 efinance 面板在重叠段全量对账。

## 使用红线（沿用 AGENTS.md）

- fuyao **指数历史**与**预计算复权价**均已实锤失真，双双禁用；
  只用其原始价、复权事件流与非价格类数据。
- 新数据族启用前每一族先与独立源交叉验证，验证记录入 docs，未验证不得进入回测。
