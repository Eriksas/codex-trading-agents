## 1. "唯一变量是指数数据"的可信度评估——**低**

文档的"唯一变量"声明无法从现有证据中证实，可能同时变化的东西至少还有 5 项：

1. **缓存层**。项目里有 `data/cache/market_scanner/index/` 这种目录（AGENTS.md 第 47 行）。重跑是否确认了缓存被清空？如果重跑脚本读的是 `data/expanded/index_daily_baostock.csv`，但实际成交 PnL 还在用 `data/cache/...` 下某次旧 run 的结果，"唯一变量"就站不住。需要 grep 全部 cache key 的生成逻辑，看 BaoStock 路径会不会复用 fuyao 的 cache 文件名。
2. **数据 fetcher 重新拉取的副作用**。切到 BaoStock 通常会触发 akshare 端的标的池重新对齐。如果"指数 + 个股 OHLCV"是在同一次回测入口里重拉的，那么个股层也变了，"唯一变量是指数"就变成"唯一变量是 BaoStock"，这是两个不同的命题。
3. **交易日历**。BaoStock 与 fuyao 在 2021–2026 这段时间至少差 1–2 个交易日（清明、端午调休、半日市）。如果 V3 用 `rebalance_date = next trading day`，差 1 个交易日的 0.3% 复利经过 5.5 年也能解释一部分 8.7pp 修正量。
4. **代码版本**。重跑用的是哪个 commit？需要 `git rev-parse HEAD` 锁定。`src/market_scanner.py` / `src/quant_core.py` 在 2026-07-03 重构（AGENTS.md 第 35 行）期间有过结构变动；如果"修正指数"和"重构"是同一次提交里完成的，变量就不是 1 个。
5. **随机性**。需要确认回测入口里没有任何 `random.seed` 依赖、bootstrap 抽样、Monte Carlo 止损路径模拟。哪怕一个 `np.random.choice` 就能让两次"同样输入"产生不同输出。

**判断**：在没有 `git diff`、`cache bust 证据`、两端 `git rev-parse` 对比的情况下，"唯一变量"是未经证实的假设，不是事实。

## 2. "修正幅度梯度"作为污染路径的证明力——**中等偏弱**

文档给出的修正幅度：
- v1 变体：-37.84% → -16.99%，修正 **+20.85pp**
- v2 变体：-13.76% → -2.99%，修正 **+10.77pp**
- V3：-9.89% → -1.19%，修正 **+8.70pp**
- legacy_momentum_v1：-22.50% → -18.64%，修正 **+3.86pp**

文档的解释："环境依赖越强 → 修正越大 → 证明是指数污染。"

替代解释至少有 3 个，且其中至少 1 个对结论的破坏力更大：

1. **参数/规则数量的退化解释**。v1 修正 20.85pp 是 v3 的 2.4 倍，但 v1 变体很可能是规则树最深的版本（含更多 gate、更多过滤、更多微结构信号）。更多规则 = 对任何单一数据输入更敏感，这不必然指向"指数污染"，可以指向"v1 自己就过拟合了"。
2. **修正方向的同号性存疑**。4 个独立策略中，3 个修正方向为正，1 个（legacy）也向正修正（+3.86pp）。**没有 1 个策略在修正后变差**。在"fuyao 污染了熊市/牛市判断"的因果链下，预期应当看到至少 1 个策略原本因错误环境信号获益，修正后归零甚至反向。**零反向修正**这一点是文档没有正面回应的。
3. **暴露量的天花板效应**。V3 平均暴露 2%，理论亏损空间被压缩到极小。8.7pp 的绝对修正在 2% 暴露下意味着"原本在刀口上跳，现在还在刀口上跳但没那么歪"。**这不能区分"指数污染"和"V3 本来就在随机游走"两个假设**。

**判断**：梯度证据与"指数污染"一致，但与"v1/v2 自身过拟合"和"V3 近似噪声"也一致。需要分项 partial correlation 才能定论，文档目前是相关当因果。

## 3. -1.19% 累计的统计置信区间——**非常宽**

直接给出基于文档数字的推导：

- 5.5 年 356 笔，平均年化笔数 64.7 笔
- 平均单笔 -0.50%（文档给定），平均暴露 2%
- 假设单笔 PnL 的截面标准差 σ 是均值的 2 倍（momentum 策略的典型量级），即 σ ≈ 1.0%（per trade, on position capital）
- 年化组合收益的标准差：σ_year ≈ 1.0% × √(64.7) ≈ 8.0%
- 5.5 年样本下的均值标准误：SE = 8.0% / √5.5 ≈ 3.4%
- -0.24% 年化的 95% CI ≈ **[-6.9%, +6.4%]**

**判断**：
- -0.24% 与"真中性"在统计上**完全无法区分**（t ≈ -0.07，p ≈ 0.94）
- 但同样**完全无法排除**"实际年化 -7% 到 +6%"的任何值
- 356 笔在 5.5 年跨度下，对低频策略来说**远不够**把年化收益的置信区间收窄到 ±2% 以内
- "近中性"是一个**无法拒绝的零假设**，不是**支持零假设的证据**——这是统计推断上的关键区别，文档目前的措辞倾向后者
- HERMES.md 第 75–78 行明确要求 10 笔以下不能作为策略结论，356 笔在数学上"够"，但对于一个 2% 暴露、5.5 年期、年化波动 ~8% 的低频策略，**有效独立样本量**（考虑持仓重叠、自相关、regime clustering）很可能打 30% 折扣，**真实独立样本 ≈ 100 笔量级**

**判断**：样本量在名义上达标，在有效样本上不达标。"近中性"是个统计学上无法证伪但也无法证实的中性陈述，文档应明确这一点，而不是把它当作有利证据。

## 4. "1.3~1.8%/年" 措辞的红线越界——**明确越线**

原文：

> 现实语境：回测中闲置资金记零收益。以 2% 平均暴露计，若 98% 资金放货基（近年约 1.5-2%/年），全账户现实预期约 +1.3~1.8%/年

越线点（对照 AGENTS.md 第 184–186 行禁止事项）：

1. **"近年约 1.5-2%/年"是隐含收益承诺**。货币基金收益不构成对未来保证，AGENTS.md 明文"不得声称收益确定"。
2. **把现金票息包装成 V3 的"现实预期"**，会让读者把 +1.3~1.8% 误读为 V3 策略表现。实际上 alpha 贡献 = 0，所有数字都来自机会成本假设。文档第 81–83 行自己承认"收益来源主要是现金，不是策略 alpha"，但前面 1.3~1.8% 那一行又把现金和策略混在一起呈现。
3. **数字精度暗示确定度**。1.3~1.8% 给出 0.5pp 的窄区间，看起来像是有依据的精算结果，实际上是 `0.98 × (1.5~2.0) + 0.02 × (-0.5) ≈ 1.2~1.7` 的算术，但读者不会做这个算术。

**建议改写**（仅供参考，critic 不替你定稿）：

> 现实语境说明（非策略表现）：本回测中 98% 时间闲置资金按 0 收益记账，alpha 部分接近 0。若读者希望用近年货币基金区间（1.5~2%/年）粗估 98% 现金部分的机会成本、加上 2% 暴露部分的近零回测收益，**回测口径下的合成数字**约 +1.3~1.8%/年；此为**回测期历史外推**，**不构成对未来收益的预测或承诺**，且其中 alpha ≈ 0，**全部来自现金票息假设**，不应被视为 V3 策略本身的盈利能力。

要点：把"现实预期"改成"回测口径下的合成数字"；把"1.5-2%/年"明确为读者自填的假设；删掉任何把合成数字与策略表现挂钩的句式。

## 5. 2025H2-2026H1 牛市 +2% 的回避程度——**部分回避**

事实层：
- 文档披露：2025 全年 V3 -2.3%，2026H1 V3 +2.0%
- 同期（用户给定）：2025H2-2026H1 创业板 +95%
- V3 在 2025H2 + 2026H1 这段牛市里，**最乐观**的累加路径是 -2.3% + 2.0% = -0.3%（若 2025 全年负收益全部来自 H1，则 H2 净赚 ~2.0%；最坏情况是 H2 赚的都被 H1 亏掉了）

**问题点**：
- 文档没有给 V3 在 2025H2-2026H1 的**单段**累计。给出的是全年 + 半年的颗粒度，对牛市这一关键时期的诊断颗粒度太粗
- 文档也没有给 Sharpe / Sortino / Calmar。**对一个牛市 +95% 而策略 +2% 的组合，唯一能证明它不是"涨不动跌不多"的有效证据是 risk-adjusted alpha**（即在更早熊市里它是否真的少亏很多）。文档没给这个数
- 按文档叙述，V3 的 environment gate "只在积极环境开仓"——牛市本应是"积极环境"密度最高的时段，而 V3 仍只赚 2%，**说明 gate 本身在牛市是过度收紧的**，这一点文档在"如何解读"第 1 条里把 +2% 归因于"风险预算仓位"，但**没有正面回答：牛市里 gate 放行了吗？放行日里 V3 相对创业板的 beta 是多少？**

**判断**：文档没有回避数据，但回避了**对数据最直接的解读**——在 95% 牛市里赚 2% 几乎等于"市场环境识别模块失效"，这比 -9.89% → -1.19% 的修正是更值得讨论的工程问题。建议补一张表：2025H2-2026H1 的月度 V3 收益 vs 创业板 ETF 收益 + 当月 gate 状态（绿/黄/红）。

## 总体判断

文档**做了正确的事**（识别指数失真、隔离污染源、修正红线）。**但结论措辞越界了**：
- "唯一变量"的实证支撑缺失

修正幅度 +8.7pp 听起来很乐观，但**对一个平均暴露 2%、年化波动 ~8% 的策略，8.7pp 的修正在 5.5 年里完全落在噪声带内**。文档最大的工程价值是**排除了一种系统性错误**，不是证明 V3 有效。两者需要分开陈述，目前的文档把这两件事糅在一起，是最值得修的地方。
