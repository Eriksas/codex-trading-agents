# 红利低波预注册复检：判决书（2026-07-10）

代码：`research/dividend_lowvol_study.py`（预注册协议在 docstring）
结果：`output/dividend_lowvol_study/results.csv`
反方审查：Hermes（本文 §3 收录采纳与反驳）

## 1. 按预注册协议的判决：**不过标，存档**

预注册标准为「修正幸存者偏差后全四段累计非负 **且** 各段 MDD ≤ 15%」。
实测：累计腿 12/12 行通过（项目十年数据上首个全正家族）；**MDD 腿 10/12 行
不通过**（divlv_25 三段达 -20%~-25%）。按协议原文执行：本轮不晋级。
我在结果沟通中曾提出「60% 固定比例缩放进约束带」——采纳反方意见，
该操作属事后补救，不得用于援救本轮判定；如需架构层方案须另行预注册。

## 2. 判决后的三项核查（反方要求，全部执行）

1. **标准参数敏感性（252 日 TTM / 63 日季调）**：烧毁段翻负
   （std_25 -1.5%、std_50 -3.1%）——**「四段全正」是参数脆弱的**，
   244/60 版本的全正含参数运气。但**「十年累计为正」参数稳健**：
   全部 5 个配置十年复合 +60%~+110%，2016-2023 两段全部强正，
   弱点集中于 2024 后（风格拥挤与成长轮动）。
2. **退市股分红覆盖率：0%**（240 只 2016 后退市股在分红事件流中零记录）——
   红利策略受幸存者偏差的伤害机制比等权更直接（高息暴雷股被回测"从未买过"），
   通用 -1.2%/年修正对本家族偏低，精确量化待 BaoStock 分红补拉（已列待办）。
3. 除权日记账滞后：A 股分红集中 6-8 月，滚动股息率在除权季前系统性低估
   即将派息标的；事件流无公告日字段，该滞后为数据边界，方向为信号稀释。

## 3. 对反方审查的采纳与反驳

采纳：协议判定从严执行；「惯例参数」措辞过度包装（244/vol120下半/等权
top-N/60日均为**项目默认值**而非公开指数参数，本文更正）；家族先验
（红利 2021-2024 顺风为公开知识）构成选择偏差，证据强度应打折。

反驳（事实层）：审查将结果表 `avg_exposure` 列（0.67-0.83）解读为
「已实施的隐蔽缩仓/变相调参」并展开整节批评——**事实：本研究未做任何
缩放**，暴露 <1 来自信号暖机期（vol120/股息窗在段初不满）与季调整仓的
现金间隙，为引擎机械属性，方向保守。另「历史 125 配置期望已出现约 8 个
全正家族」与台账不符：此前四段全正的实际数量为零（唯一 3/3 的 bounce
已在第四段折翼）。

## 4. 最终定性与去向

- **定性**：红利低波是项目十年数据上唯一「十年累计正收益、且该性质
  参数稳健」的家族；但无全天候性（2024 后弱、MDD 达 -25%）、
  受幸存者偏差污染程度未完全量化、家族选择带先验。
  它不是被证明的 alpha，是**有据可查的风格 beta 候选**。
- **去向**：
  1. 本轮按协议存档（不过标）。
  2. 新增 forward 观察线：divlv_25 名单季度 paper 记录（纯研究观察，
     与 bounce/gate 同级，不构成任何配置建议）。
  3. 底仓/杠铃等真实账户架构问题超出回测范畴，属用户决策；
     项目提供的是以上如实证据。
  4. 待办：BaoStock 补拉退市股分红史 → 重算修正系数。
