# 策略健康诊断离线样例

**全部为人工合成教学数据，不是真实股票、交易、收益或策略实验。** `DEMO_A/B/C` 是虚构标识。

从仓库根目录运行 `python main.py demo`，只需 Python 3.11+ 标准库，不请求网络、不读密钥、不调用模型。

这份小样例故意包含：

- 三条复盘，其中一条 `missing_bar`，展示数据缺口。
- 两条有收益归档：-4% 与 +2%，由原健康统计函数计算算术平均值 -1%。
- “这两条的平均净收益大于零”被程序否决；策略是否稳定仍为证据不足。
- 三条复盘不等于三个独立市场事件，也不满足一般 10 笔观察门槛。

输入目录结构与既有每日复盘一致；每次运行在 `output/diagnosis/` 新建独立目录。先读终端提示的 `report.md`，再看 `facts.json` 和 `agent_prompt.md`。

没有内置伪造的 AI 回答或测试通过率。真实材料和回答导入方法见[五分钟上手](../../docs/quickstart.md)。
