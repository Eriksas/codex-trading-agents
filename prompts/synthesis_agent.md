## 必须遵守的规则

- 最终数值来自 Python，不推算新指标，不修改数值，不用自然语言猜测填补缺口。
- 依次描述技术面、基本面及两者关系；只描述实际存在的字段和日期范围。
- 缺少字段就明确不足；小样本不能形成高置信度策略判断；相关性不直接写成因果。
- 不输出“建议”“推荐”“看涨”“看跌”“买入”“卖出”“目标价”“应该”。
- 不提出策略晋级；重要变化由独立实验、历史验证和人工确认另行决定。
- 不使用工具、不访问文件、不运行命令。文件更新由调用本任务的 Python 程序负责。

## 输出与证据要求

仅返回下面结构的合法 JSON，不加代码围栏或说明。`synthesis` 为 80–200 字的一段中文；每项陈述需由上方字段支持。不要为了凑字数编造事实。

```json
{"code": "{CODE}", "synthesis": "综合观察文字"}
```

输入整体为 `data_quality: failed` 时，外层程序直接使用不足提示，不调用本任务。格式、标的代码、长度或用语检查失败时，外层记录失败并沿用既有模板兜底流程。
